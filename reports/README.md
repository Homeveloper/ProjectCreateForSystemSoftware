# Результаты проверок

Каталоги названы по состоянию продукта, на котором выполнялся прогон.

| Каталог | Состояние | Назначение |
|---|---|---|
| `baseline-v0.1.0/` | тег `v0.1.0` | исходное состояние: проверки до улучшения |

Прогон воспроизводится командой:

```
scripts/check.sh <имя-каталога>
```

Состав отчётов:

| Файл | Инструмент | Что показывает |
|---|---|---|
| `gofmt.txt` | gofmt | файлы с нарушением форматирования |
| `vet.txt` | go vet | подозрительные конструкции |
| `test.txt` | go test | результат тестов (подробный вывод) |
| `cover.txt`, `coverage.out`, `coverage-total.txt` | go test -cover | покрытие тестами |
| `staticcheck.txt` | staticcheck | статический анализ |
| `gosec.txt` | gosec | типовые дефекты безопасности в коде |
| `govulncheck.txt` | govulncheck | известные уязвимости в зависимостях |

Интерпретация результатов и решение о выпуске — в [../project.md](../project.md).
