# Свойства безопасности

Документ описывает, что продукт защищает, от чего и какие риски приняты.
Результаты проверок и решение о выпуске — в [project.md](project.md).

## Что считается недоверенным

| Вход | Источник | Почему недоверенный |
|---|---|---|
| Файл конфигурации | аргумент командной строки | может прийти из репозитория, архива или сети |
| Файл схемы | аргумент командной строки | то же |
| Имя файла результата (`-o`) | аргумент командной строки | может содержать переходы по каталогам |

## Что защищается

| Ценность | Угроза | Мера |
|---|---|---|
| Доступность машины, где выполняется утилита | исчерпание памяти или стека при разборе | предел размера 10 МиБ, предел глубины 64, оценка глубины до разбора, ограничения раскрытия псевдонимов в `yaml.v3` |
| Секреты внутри конфигурации | попадание в журналы, вывод сборки, отчёты | содержимое не включается в ошибки, значения секретных полей заменяются маской, подробный режим выводит скрытую копию |
| Файловая система вне рабочего каталога | запись за пределы `--out-dir` | проверка принадлежности пути каталогу, отказ на абсолютных путях и символьных ссылках |
| Секреты в файле результата | чтение посторонним пользователем | права `0600` на файл, `0700` на каталог |

## Границы

Продукт сознательно не решает следующие задачи:

- не шифрует конфигурации и не управляет ключами;
- не проверяет подлинность источника файла (подписи, контрольные суммы);
- не изолирует разбор в отдельном процессе или песочнице;
- поддерживает не всю спецификацию JSON Schema, а объявленное подмножество.

## Принятые остаточные риски

**Чтение файла по пути из аргументов командной строки (gosec G304, две находки
в `internal/config/load.go` и `internal/config/schema.go`).**
Утилита по назначению читает файл, который назвал пользователь, и выполняется
с его правами: прочитать тот же файл напрямую он может и без утилиты.
Повышения привилегий не происходит, поэтому находки приняты.
Риск станет значимым, если утилиту встроят в службу, получающую путь
из недоверенного источника. Для такого применения потребуется ограничение
чтения корневым каталогом; в текущем выпуске оно не реализовано.

**Отсутствие ограничения по времени разбора.**
Пределы заданы по размеру и глубине, но не по длительности. Для консольной
утилиты, запускаемой человеком или сборочным конвейером с собственным
лимитом времени, это приемлемо.

## Как сообщить о проблеме

Учебный проект, процесс приёма сообщений об уязвимостях не выстроен.
Замечания — через issues репозитория.
